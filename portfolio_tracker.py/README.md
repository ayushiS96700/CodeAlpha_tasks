# 📈 Advanced Stock Portfolio Tracker

## 📌 Overview

The **Advanced Stock Portfolio Tracker** is a Python-based console application that helps users manage and monitor their stock investments. Users can add stocks, calculate investment value, track profit or loss, save portfolio data, and visualize portfolio allocation using a pie chart.

This project demonstrates the use of Python programming, file handling, JSON data storage, data visualization, and basic financial calculations.

## 🚀 Features

* Add stocks to your portfolio
* Track investment and current market value
* Calculate individual and overall profit/loss
* Save portfolio data automatically in a JSON file
* Load previously saved portfolio on startup
* Display portfolio allocation using a pie chart
* User-friendly console interface
* Input validation and error handling

## 🛠️ Technologies Used

* Python 3
* JSON
* Matplotlib
* OS Module

## ▶️ Installation

Clone the repository:

https://github.com/ayushiS96700/CodeAlpha_tasks/tree/main/portfolio_tracker.py

Move into the project directory:

cd Portfolio-Tracker.py


Install the required library:

pip install -r requirements.txt


## ▶️ Run the Project

python main.py


## 📋 Menu Options

When the application starts, the following menu is displayed:

1. Add Stock
2. View Portfolio Summary
3. Show Portfolio Chart
4. Exit

## 📈 Portfolio Summary

The application displays:

* Stock Symbol
* Quantity
* Buying Price
* Current Market Price
* Profit/Loss
* Total Investment
* Current Portfolio Value
* Overall Profit/Loss


## 📊 Portfolio Visualization

The project uses **Matplotlib** to generate a pie chart showing the percentage allocation of each stock in the portfolio.

## 💾 Data Storage

Portfolio information is stored locally in:

portfolio_data.json


The file is automatically created after adding the first stock.
